# TapTile promotional pages

Open `index.html` for the responsive landing page, `privacy.html` for the privacy policy,
and `banner.html` for the 1024 × 500 promotional composition. No build step or remote
runtime dependencies are required. The pages remain local; deployment is separate.

The ice-crystal world and app icon are original generated promotional illustrations.
The phone frame is CSS. Its screen image is a retained in-game capture, not part of
the promotional illustration. Screenshots must be placed inside the phone frame.

The privacy text reflects the integrated Google Mobile Ads, Unity Ads, Firebase
Analytics/Crashlytics and Unity runtime services. Privacy contact continues to use
the support address from the official Google Play listing.
